# 🚌 راحة ضيف | Raha Dhaif

منصة لإدارة تفويج الحافلات وحجز استراحات الطرق لخدمة ضيوف الرحمن



---

## 📖 نبذة عن المشروع

راحة ضيف منصة تربط سائقي حافلات ضيوف الرحمن بـالاستراحات ومحطات الطرق على الطرق السريعة بين مكة المكرمة والمدينة المنورة وجدة.

تساعد المنصة السائق على اختيار الاستراحة المناسبة وحجز رصيف للحافلة قبل الوصول، فيقل الازدحام وينتظم التفويج. وتساعد ملاك الاستراحات على إدارة الحجوزات والطاقة الاستيعابية والخدمات المقدمة.

## 🎯 المشكلة التي نحلها

- ازدحام الحافلات في الاستراحات وقت المواسم (الحج والعمرة)
- صعوبة معرفة الاستراحات المتاحة وخدماتها ومستوى الزحام فيها
- غياب نظام حجز منظم لأرصفة الحافلات

## ✨ المميزات

### للسائق 🚍
- استعراض الاستراحات مع التقييم وعدد الأرصفة المتاحة
- البحث عن الاستراحات حسب المدينة
- حجز موعد وصول وتحديد عدد الحافلات
- تصريح دخول بـ QR Code لكل حجز
- تقييم الاستراحات وكتابة المراجعات
- نظام نقاط ولاء ومكافآت
- الإبلاغ عن أعطال المرافق

### لمالك الاستراحة 🏪
- إدارة بيانات الاستراحة وخدماتها وصورها
- متابعة الحجوزات وتأكيدها
- متابعة نسبة الإشغال ومستوى الازدحام
- متابعة المعاملات المالية والأرباح

### للمشرف 🛠️
- إدارة المستخدمين والاستراحات
- متابعة بلاغات الصيانة

### الخدمات المتوفرة في الاستراحات
🕌 مصلى · 🍽️ مطاعم ومقاهي · 🔧 صيانة حافلات وإطارات · 🚻 دورات مياه مهيأة لذوي الاحتياجات · 🛋️ صالة استراحة للسائقين

## 🧱 التقنيات المستخدمة

| الجزء | التقنية |
| --- | --- |
| تطبيق الجوال | Flutter و Dart (واجهة عربية RTL، خط Tajawal) |
| الواجهة الخلفية (API) | PHP 8.2 و REST API |

## 🚀 طريقة التشغيل

### 1) تشغيل الـ API باستخدام Docker

cd raha-dhaif-api
docker compose up --build


يشتغل الـ API على: http://localhost:8080

### أو باستخدام XAMPP

1. شغّل Apache و MySQL من لوحة XAMPP
2. استورد قاعدة البيانات:
      /Applications/XAMPP/xamppfiles/bin/mysql -u root rahadhaif_api < sql/init.sql
   
3. انسخ ملفات الـ API إلى /Applications/XAMPP/htdocs/rahadhaif_api
4. افتح: http://localhost/rahadhaif_api/index.php/rest-stops

### 2) تشغيل تطبيق Flutter

cd raha_guest_app
flutter pub get
flutter run


عنوان الـ API حسب الجهاز:
- محاكي Android: http://10.0.2.2/rahadhaif_api/index.php
- محاكي iOS: http://127.0.0.1/rahadhaif_api/index.php
- جهاز حقيقي: http://<IP-جهازك>/rahadhaif_api/index.php
