# -
إدارة مرافق ونقاط استراحة ضيوف الرحمن (قائمة للاستراحات والمحطات التي يمكن لاصحاب الحملات وسائقي الباصات معرفتها والتسجيل فيها)
منصة راحة ضيف (Rahat Daif)
منصة رقمية متكاملة مخصصة لإدارة محطات الاستراحة، سجلات حافلات النقل، ومواقع المسارات (مثل محطة جرول ومحطة كدي)، بالإضافة إلى تنظيم الطلبات وجداول نسب العمولات.
🚀 نبذة عن المشروع
تهدف المنصة إلى تسهيل عمليات تتبع الحركات والخدمات اللوجستية للمعتمرين والضيوف بجودة وفعالية عالية، وتقديم تجربة مستخدم سلسة ومرنة.
👥 فريق العمل
قائد المشروع: جيوان القرني
تطوير واجهات المستخدم (Frontend): ريما الساعدي
تطوير تطبيقات الجوال (Mobile): رولا الحارثي
تطوير البنية الخلفية للموقع (Backend - Website): ريتاج المالكي
تطوير البنية الخلفية للجوال (Backend - Mobile): ليان
إدارة وقواعد البيانات (Database): أهداب
🛠️ التقنيات المستخدمة
Frontend: HTML5, CSS3, JavaScript
Backend & Database: MySQL, XAMPP
Mobile App: Android Studio (Kotlin & XML)
API Testing: Postman
